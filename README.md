# AI 时代个人操作系统

> 副标题：认知、健康与财富自由的地球 Online 攻略
> 内容来源：播客《对话孙宇晨：年轻人如何抓住 AI 时代的机会？》（对谈人：邵艾伦 Alan，全片约 4 小时 22 分）
> 形态：Markdown 源 + 单文件在线网页 + 可打印 PDF｜零依赖、零构建工具、可离线

---

## 这本书是什么

同一场 4 小时 22 分长访谈的**两种读法**合订：

| 部分 | 来源 | 体量 | 读法 |
| --- | --- | --- | --- |
| **卷首** | 编者撰写 | 3 节 | 先读《全书核心观点速览》，15 分钟拿到全部结论 |
| **上部·体系篇** | 《深度精读手册》（123 页 PDF） | 15 章 + 3 附录 | 主线：每章「核心观点 → 建议 → 具体办法 → 金句原话（带原片时间戳）→ 本章要点」 |
| **下部·对话实录** | 《对话孙宇晨》（79 页图片型 PDF） | 9 章 + 尾声 + 2 附录 | 原话：逐字文稿，保留「孙宇晨：」「邵艾伦：」说话人标记 |
| **章节对应与检索** | 合稿生成 | 对应表 + 时间戳说明 | 上部第 N 章 ↔ 原片时间 ↔ 下部哪一节 |

全书 **12.8 万中文字**、**1,038 处原片时间戳**、**207 条金句条目**。

## 目录结构

```
AI时代个人操作系统/
├── index.html          ← 成品：整本站（双击即读，手机浏览器同样可用）
├── print.html          ← 打印版（浏览器 Ctrl+P 即可存成 PDF）
├── 更新网页.bat         ← 一键更新：改了书稿后双击它，网页自动重排（Windows）
├── assets/
│   ├── book.css        ← 全部样式（含深色模式与 A4 打印样式）
│   ├── book.js         ← 目录折叠 / 滚动高亮 / 主题切换
│   └── search.js       ← 构建期生成的全文检索索引（无需后端）
├── src/
│   └── book.md         ← 唯一源文件（Markdown 全文，改它即可重出整本书）
├── build/
│   ├── md2site.py      ← 排印器：把 Markdown 排成网页（纯 Python 标准库，零依赖）
│   └── make.py         ← 一键更新的入口（书名等参数写在这里）
└── README.md
```

## 怎么用

- **本地阅读**：双击 `index.html`（无需服务器、无需联网，手机把文件拷进去也能读）。
- **搜索**：页面顶部搜索框，或按 `/` 聚焦、`Esc` 关闭，支持全文检索与高亮片段。
- **导出 PDF**：用浏览器打开 `print.html` → `Ctrl+P` → 目标选「另存为 PDF」（已内置 A4 分页样式，章前自动分页、表格不跨页断开）。
- **发布到 GitHub Pages**：把本目录内容推到仓库根目录（或 `docs/`），在仓库 Settings → Pages 选择分支即可；`index.html` 会被自动识别为首页。
- **重新生成**（改了 `src/book.md` 之后）：
  - **最简单**：双击目录里的 `更新网页.bat`，等窗口显示 Finished，再打开 `index.html` 就是新版。
  - 命令行等价写法：`py -3 build/make.py`（只依赖 Python 3，无第三方库）。
  - 书名、副标题、作者这些文字写在 `build/make.py` 顶部的 `TITLE / SUBTITLE / AUTHOR / NOTE` 里，想改直接改那四行。

## 来源、方法与边界

- **上部**来自《孙宇晨 AI 时代机会 · 深度精读手册》（123 页，内嵌 1,038 处 `（原片 HH:MM:SS）` 时间戳）。本次做的是**格式还原**（PDF → Markdown），未改动观点与措辞；原作中的 15 章按**时间顺序**编排，每章约 17.5 分钟。
- **下部**来自《对话孙宇晨：年轻人如何抓住 AI 时代的机会》（79 页逐字文稿）。原文件是**图片型 PDF、无文字层**，本次做了逐页人工校对式转录：说话人前缀、数字、英文均按原样保留。下部 9 章按**主题**编排，与上部的时间顺序不同，故用书末对应表连接。
- **边界**：本书是对一场公开发言的学习性整理。所有观点属于孙宇晨本人，对谈内容版权归原播客及其权利人所有；转录稿可能存在听写误差，凡涉及事实与数字，请以原片为准。本书不构成投资、医疗或任何人生决策建议，仅供学习交流。
